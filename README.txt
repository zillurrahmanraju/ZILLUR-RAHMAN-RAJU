কোন ফাইলে কী আছে
-----------------
index.html   -> শুধু কাঠামো। সাধারণত ধরার দরকার নেই।
style.css    -> ডিজাইন। ছবির জায়গা, রঙ, সাইজ। (উপরে ছবির সেটিং আছে)
config.js    -> আপনার সব লেখা ও তথ্য। নাম, ইমেইল, প্রজেক্ট, লিংক, পড়াশোনা, গল্প।
script.js    -> config.js এর তথ্য দিয়ে সাইট সাজায়। ধরার দরকার নেই।
rajuu.jpg    -> আপনার ছবি।

কী বদলাতে কোন ফাইল
--------------------
ছবি ডানে/বাঁয়ে সরানো   -> style.css (একদম উপরে --photo-right)
রঙ বদলানো              -> style.css (--amber, --blue)
নাম/ইমেইল/ফোন/লিংক      -> config.js
প্রজেক্ট যোগ করা         -> config.js এর projects
প্রজেক্টের ছবি বদলানো    -> projects-এর image-এ "Raju all pic/ছবির-নাম.jpg" দিন
নতুন ছবি দেওয়া          -> ছবি ফোল্ডারে রাখুন, config.js এ photo: "নতুন-নাম.jpg"

সমস্যা হলে
----------
সাইট ফাঁকা দেখালে      -> config.js এ কোনো " বা , বাদ পড়েছে। F12 চেপে Console এ লাল লেখা দেখুন, লাইন নম্বর দেওয়া থাকবে।
ছবি আসছে না           -> ছবির নাম ও config.js এর photo: "..." হুবহু এক কিনা দেখুন (বড়/ছোট অক্ষরও)।
গ্যালারির ছবি আসছে না -> index.html-এর পাশে Raju all pic ফোল্ডারটি সম্পূর্ণ রাখুন এবং সাইটে আপলোড/ডিপ্লয় করার সময় ওই ফোল্ডারটিও সঙ্গে দিন।
কিছু বদলাচ্ছে না      -> Ctrl+S দিয়ে সেভ করে ব্রাউজারে Ctrl+Shift+R দিন।
